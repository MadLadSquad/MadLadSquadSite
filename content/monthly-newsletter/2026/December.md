Welcome to the December 2026 edition of the monthly newsletter!

## UntitledDesktop
### Another code review set and UntitledImGuiFramework 3.0 delay
We extended our release timeline for the 3.0 release of the [UntitledImGuiFramework](https://github.com/MadLadSquad/UntitledImGuiFramework)
by another couple of weeks as we prepare for another large batch of code review changes to land for most libraries.

We're also using the framework for 2 projects at [Heapforge](https://heapforge.com), which introduced new changes to the windowing integration
which require more care an testing. We plan to be ready with the code review by the end of December.

### pkggen 1.0 delayed
Due to a lack of resources the 1.0 release of pkggen is also delayed until the end of December, however the currentgit version should be
good enough for most users, even though it is not thoroughly reviewed and might contain bugs or security issues. Use it at your own risk.

The new pkggen packaging workflow is also delayed until version 1.0 of pkggen is released.

### UntitledFontManager, UntitledDEPolkitAgent, UntitledFileManager and UntitledImGuiFileManager delayed
The initial releases of all of these projects are currently delayed until Q1 of 2027 due to a lack of resources associated with the
preparations for releasing the 3.0 release of the UntitledImGuiFramework and the 1.0 release of pkggen.

## Heapforge ID 1.0
The 1.0 release of the Heapforge ID accounts system is planned to be ready by the end of December. After its release we expect to launch
the 1.0 releases of Youyin and of another unannounced service somewhere in Q1 of 2027.

We expect that revenue earned by services connected with Heapforge ID should be enough to completely fund both Heapforge and MadLadSquad 
for the foreseeable future.
