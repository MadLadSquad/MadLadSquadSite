Welcome to the October 2026 edition of the monthly newsletter!

## UntitledDesktop
### Bug fixes, security patches and feature improvements
In August we decided to try using AI tools for code review to check for bugs, security issues and incomplete features for each
UntitledDesktop library and application. As a result, we stacked a large amount of diffs which we plan to review and officially
publish by the end of October

### New libraries and applications
By the end of October/the beginning of November we also plan to publish the 1.0 releases of the following libraries and applications:

1. UntitledFontManager - a system font atlas builder library
1. UntitledDEPolkitAgent - a polkit agent
1. UntitledImGuiFileManager - a fully-featured and highly extensible file manager widget for dear imgui
1. UntitledFileManager - a fully-featured cross-platform file manager built using the UntitledImGuiFramework

These applications and libraries were part of the original UntitledDesktop development plan from 2022 and 2023, but due
to a large amount of tasks that overshadowed them in priority we did not have the ability to develop them into a
releaseable state.
